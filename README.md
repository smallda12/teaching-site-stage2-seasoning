# 這是什麼：離線教學網站使用說明

適用：第二學習階段，自然科學，第一學期第 3 單元，第 9～12 週。

## 開啟方式

1. 完整解壓縮網站資料夾，保留 index.html、css、js、assets 的相對位置。
2. 雙擊 index.html，以 Edge 或 Chrome 開啟。
3. 第一次使用先按播放或朗讀按鈕，讓瀏覽器允許本頁播放音訊。

## 教學內容

四個重點：五官安全觀察、調味品分類、調味品用途、綠豆湯製作。
完整 70 頁教材圖、10 張學習圖卡、16 題兩選一互動評量、主影片與 4 支主題短片、86 段語音。
每個重點含 3 頁前置教學、3 題正式評量、2 頁深化教學及 1 題形成性評量。
可由影片分區選擇短片或完整教學影片，也可下載列印簡報、圖卡、評量練習單與學習單 PDF。

## 教室與公開模式

雙擊開啟的 file 模式為教室版：可使用本機點名與照片功能；資料保留在使用的電腦。
HTTP／HTTPS 模式為公開版：關閉照片上傳。
點名名單、作答進度與照片均不包含在交付包；更換瀏覽器或電腦不會自動同步。

## 操作提醒

未知粉末不開袋、不試吃，停止並找老師。
嗅聞由老師管理；觸摸改採隔袋摸。熱鍋、火源及加熱由老師處理，冷卻後才進行學生操作。
外部延伸影片須連線。本單元已加入老師核可的 2 支延伸影片；依影片卡上的分段觀看與安全操作提醒使用。
